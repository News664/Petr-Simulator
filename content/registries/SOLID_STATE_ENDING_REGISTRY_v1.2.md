# SOLID STATE — Ending Registry
## Version 1.2 — adds END-MED-003 `Benefit Approved`

**Canonical source:** `SOLID_STATE_ENDING_REGISTRY_v1.2.csv`

Ordinary solid Permanent Forms default to `Unconscious`; temporal material uses `Suspended` where applicable. `Uncertain` needs no authorization. `Continuous`, `Intermittent`, and `Displaced` require explicit authorization.

H2B adds `END-MED-003` for the Basic Continuity Insurance chain. It is distinct from `END-MED-002 Cheap Immortality`: the benefit works exactly as promised, and the approval does not cover continued mobility.
